# Практична робота 7


## Що конкретно я зробив у Lab-7:

1. **Налаштував клас `Drone.cs` для серіалізації:**
   * Додав атрибути `[JsonPropertyName]` до головних характеристик (`Model` -> `drone_model`, `BatteryCapacity` -> `battery_mah`, `MaxSpeed` -> `top_speed_kmh`).
   * Додав атрибут `[JsonIgnore]` до другорядних та службових властивостей (`Id`, `Status`, `CurrentBatteryLevel`, `RemainingEnergy`), щоб у JSON записувалися тільки основні дані.
   * Налаштував метод `ToString()` для виведення даних через роздільник `;`.

2. **Реалізував роботу з файлами у `DroneManager.cs`:**
   * `SaveToCsv` та `LoadFromCsv`: зберігаю колекцію з обов'язковим заголовком. Під час читання заголовок пропускаю, а кожен рядок перевіряю через `TryParse()` — коректні дрони додаються до списку, а «биті» рядки ігноруються.
   * `SaveToJson` та `LoadFromJson`: серіалізую та десеріалізую всю колекцію цілком за допомогою `JsonSerializer`. Зчитані об'єкти додаються до існуючих у списку.
   * `ClearCollection`: додав метод для повного очищення списку та скидання лічильника ID.

3. **Оновив консольне меню (`Program.cs`):**
   * Додав підменю у пункті **7** (збереження у CSV або JSON) та пункті **8** (зчитування з CSV або JSON з виведенням кількості завантажених об'єктів).
   * Додав пункт **9** для швидкого очищення колекції.

4. **Розширив модульні тести (`DroneManagerTests.cs`):**
   * Написав нові юніт-тести MSTest для перевірки очищення списку, збереження/читання JSON (з перевіркою перейменованих полів) та стійкості читання CSV при наявності пошкоджених рядків.

## Як запустити:
